# 🛒 E-Commerce Website

A modern, responsive frontend for an e-commerce platform, built with **HTML, CSS, and JavaScript** to provide a smooth shopping experience with a clean UI and reusable components.

---

## 🚀 Features

* 🏬 Product listing page
* 🔍 Search & filter products
* 🛍️ Add-to-cart functionality
* 🧾 Cart page with quantity updates
* 📱 Fully responsive design (mobile & desktop)
* ⚡ Optimized for speed and performance

---

## 🧰 Tech Stack

* HTML
* CSS
* JavaScript
